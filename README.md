# Sports Event Management System

A desktop application built with Python and Tkinter for managing participants in sports events.

## Features

- Add participants with ID, name, sport and other details
- Search participants by Participant ID
- Update existing participant records
- Remove participants (with confirmation)
- View all registered participants in a table
- Input validation for mandatory fields

Supported sports: Cricket, Football, Basketball, Badminton, Volleyball, Athletics, Chess, Tennis.

## Requirements

- Python 3.x
- Tkinter (included with most Python installations; on Debian/Ubuntu install `python3-tk`)

## Running the app

```bash
python sports_event_management.py
```

## Note

Records are stored in memory and are cleared when the application is closed.
